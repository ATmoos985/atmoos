## 有则填写

- 论文 / 报告：作者顺序、标题、发表渠道、年份、链接与发表状态。
- 奖项 / 竞赛：名称、主办方、时间、等级和个人 / 团队身份。
- 开源贡献：仓库、PR、本人负责的部分与链接。
- 证书、语言能力、教学 / 志愿经历。
- 城市、求职状态、可开始时间：与 CV 用途相关时提供。
